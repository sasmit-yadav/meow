SET-A Q2. TCP client-server that returns the word count and vowel count of a sentence.

Server:

import socket

server = socket.socket(socket.AF_INET, socket.SOCK_STREAM)

server.bind(('localhost',5000))

server.listen(1)

print("waiting for connection")

conn,addr = server.accept()

print("client connected")

sentence = conn.recv(1024).decode()

words = len(sentence.split())

vowels = 0

for ch in sentence.lower():
    if ch in "aeiou":
        vowels += 1

result = "Words: " + str(words) + ", Vowels: " + str(vowels)

conn.send(result.encode())
conn.close()
server.close()


Client:

import socket

client = socket.socket(socket.AF_INET, socket.SOCK_STREAM)

client.connect(("localhost", 5000))

sentence = input("enter a sentence ")

client.send(sentence.encode())

client.shutdown(socket.SHUT_WR)

result = client.recv(1024).decode()

print(result)

client.close()


SET-B Q2. TCP client-server that checks whether a number is a Perfect number (Yes/No).

Server:

import socket

server = socket.socket(socket.AF_INET, socket.SOCK_STREAM)

server.bind(('localhost',5000))

server.listen(1)

print("waiting for connection")

conn,addr = server.accept()

print("client connected")

data = conn.recv(1024).decode()

n = int(data)

sum_of_divisors = 0

for i in range(1, n):
    if n % i == 0:
        sum_of_divisors += i

if sum_of_divisors == n:
    result = "Yes"
else:
    result = "No"

conn.send(result.encode())
conn.close()
server.close()


Client:

import socket

client = socket.socket(socket.AF_INET, socket.SOCK_STREAM)

client.connect(("localhost", 5000))

number = input("enter a number ")

client.send(number.encode())

result = client.recv(1024).decode()

print("perfect number", result)

client.close()


ODD Q2. TCP client-server for GCD ("GCD A B") and Fibonacci ("FIB N") with error message for negative/invalid input.

Server:

import socket
import math

server = socket.socket(socket.AF_INET, socket.SOCK_STREAM)

server.bind(('localhost',5000))

server.listen(1)

print("waiting for connection")

conn,addr = server.accept()

print("client connected")

data = conn.recv(1024).decode()

parts = data.split()

if len(parts) == 3 and parts[0].upper() == "GCD":
    try:
        a = int(parts[1])
        b = int(parts[2])
        if a <= 0 or b <= 0:
            result = "Error: A and B must be positive numbers"
        else:
            result = "GCD of " + str(a) + " and " + str(b) + " is " + str(math.gcd(a, b))
    except ValueError:
        result = "Error: A and B must be valid numbers"
elif len(parts) == 2 and parts[0].upper() == "FIB":
    try:
        n = int(parts[1])
        if n <= 0:
            result = "Error: N must be a positive number"
        else:
            fib = []
            x, y = 0, 1
            for i in range(n):
                fib.append(str(x))
                x, y = y, x + y
            result = ", ".join(fib)
    except ValueError:
        result = "Error: N must be a valid number"
else:
    result = "Error: invalid request, use GCD A B or FIB N"

conn.send(result.encode())
conn.close()
server.close()


Client:

import socket

client = socket.socket(socket.AF_INET, socket.SOCK_STREAM)

client.connect(("localhost", 5000))

request = input("enter request (GCD A B or FIB N) ")

client.send(request.encode())

client.shutdown(socket.SHUT_WR)

result = client.recv(1024).decode()

print(result)

client.close()


EVEN Q2. TCP client-server for string reversal ("REVERSE text") and palindrome check ("PALINDROME text") with error message for empty input.

Server:

import socket

server = socket.socket(socket.AF_INET, socket.SOCK_STREAM)

server.bind(('localhost',5000))

server.listen(1)

print("waiting for connection")

conn,addr = server.accept()

print("client connected")

data = conn.recv(1024).decode().strip()

parts = data.split(" ", 1)

command = parts[0].upper()

if data == "" or len(parts) < 2 or parts[1].strip() == "":
    result = "Error: input text is empty or invalid"
elif command == "REVERSE":
    text = parts[1].strip()
    result = text[::-1]
elif command == "PALINDROME":
    text = parts[1].strip()
    if text.lower() == text.lower()[::-1]:
        result = text + " is a palindrome."
    else:
        result = text + " is not a palindrome."
else:
    result = "Error: invalid request, use REVERSE text or PALINDROME text"

conn.send(result.encode())
conn.close()
server.close()


Client:

import socket

client = socket.socket(socket.AF_INET, socket.SOCK_STREAM)

client.connect(("localhost", 5000))

request = input("enter request (REVERSE text or PALINDROME text) ")

client.send(request.encode())

client.shutdown(socket.SHUT_WR)

result = client.recv(1024).decode()

print(result)

client.close()

WIRESHARK - ODD MACHINE Q1
============================================================

1. Total number of DNS queries and responses, with display filter.
dns
dns.flags.response == 0
dns.flags.response == 1
Count = "Displayed" in the status bar.

2. Most frequently queried domain name.
dns.flags.response == 0, apply Queries > Name as column, sort, most repeated name.

3. Display filters for DNS queries requesting A and AAAA records.
A: dns.qry.type == 1 && dns.flags.response == 0
AAAA: dns.qry.type == 28 && dns.flags.response == 0

4. Filter to find all DNS query types.
dns.qry.type
Statistics > DNS > Query Type

5. Top three source IPs generating the most TCP traffic.
Filter tcp, Statistics > IPv4 Statistics > Source and Destination Addresses (Limit to display filter), sort by Count.

6. Filter to display only TCP handshake packets.
tcp.flags.syn == 1 || (tcp.flags.ack == 1 && tcp.seq == 1 && tcp.ack == 1 && tcp.len == 0)

7. Filter to list out-of-order packets.
tcp.analysis.out_of_order

WIRESHARK - EVEN MACHINE Q1
============================================================

1. Duration of the captured traffic.
Statistics > Capture File Properties > Elapsed time.

2. Filter for TCP FIN packets.
tcp.flags.fin == 1

3. List all unique source IP addresses.
Statistics > IPv4 Statistics > Source and Destination Addresses > Source IPv4 Addresses.

4. Filter for TCP retransmissions.
tcp.analysis.retransmission

5. Protocol with the highest number of packets.
Statistics > Protocol Hierarchy, highest Packets value.

6. Differentiate standard and recursive DNS queries.
Recursion Desired flag in DNS > Flags.
Recursive: dns.flags.recdesired == 1
Standard: dns.flags.recdesired == 0

7. Filter for server failed DNS queries.
dns.flags.rcode == 2

WIRESHARK - SET-A Q1
============================================================

1. Packet 10: which transport layer protocol does DNS run on?
UDP (User Datagram Protocol layer in packet 10).

2. Packet 10: is it a query, its type, content, and which packet has its response?
Yes, Flags > Response = 0 (Message is a query).
Type = Queries > Type, Opcode = Standard query.
Content = Queries > Name, Type, Class IN.
Response packet = [Response In: N] field.

3. Packet 10: is it destined for the default DNS port, and its value?
Yes, UDP Destination Port = 53.
frame.number == 10 && udp.dstport == 53

4. Packet 12: how many answers are provided?
DNS > Answer RRs (dns.count.answers).

5. Time required to get the DNS response of packet 10.
Response time - time of packet 10, shown as DNS > [Time] (dns.time) in the response packet.


============================================================
WIRESHARK - SET-B Q1
============================================================

1. Packet 15: physical address of source and destination.
Ethernet II > Src (eth.src) and Dst (eth.dst).

2. Packets 18-20: segment size and actual data length in each segment.
frame.number >= 18 && frame.number <= 20
Segment size limited by MSS, data length = [TCP Segment Len] (tcp.len) of each packet.

3. Maximum segment size for source and destination.
tcp.flags.syn == 1
Source = MSS option in SYN, Destination = MSS option in SYN-ACK (tcp.options.mss_val).

4. Packet 21: number of TCP segments reassembled and length of each.
[N Reassembled TCP Segments] field in packet 21.
tcp.reassembled_in == 21

5. Time required to get the DNS response of packet 10.
Response time - time of packet 10, shown as DNS > [Time] (dns.time) in the response packet.
